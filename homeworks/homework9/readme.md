# Домашнее задание №9: Бизнес-процесс для обработки элементов инфоблока при создании

### Цель:
- автоматизация бизнес-процессов компании;
- написание интеграций со сторонними сервисами;
- создание собственных активити для упрощения работы коллег.

### Описание/Пошаговая инструкция выполнения домашнего задания:
Создать бизнес-процесс, который при создании элементов инфоблока будет создавать компании с автоматическим заполнением реквизитов из сервиса `Dadata`.

### Пошаговая инструкция:
- создать инфоблок с полями: `Сумма`, `Заказчик ИНН`, `Заказчик`, `Вид работ`;
- создать БП, который при создании элемента инфоблока будет автоматически получать данные компании из сервиса Dadata;
- добавлять компанию в CRM и обновлять поле `Заказчик` элемента.

# Решение

## Логика работы активити:
1. Получает ИНН из поля элемента инфоблока.
2. Отправляет запрос к Dadata (через `curl`) для получения данных компании.
3. Если компания не найдена в `Dadata` — возвращает ошибку, остаётся заказ, но в бизнес-процессе выдаётся ошибка о добавление компании по реквизитам
4. Если компания найдена — ищет компанию в CRM по ИНН в реквизитах.
5. Если компания существует — обновляет её реквизиты (название, КПП, ОГРН, адрес).
6. Если компании нет — создаёт новую компанию с реквизитами из Dadata.
7. Записывает ID компании в поле `Заказчик` элемента инфоблока.
8. Активити вызывается как при добавлении так и при редактировании элемента

## Кастомное активити «Поиск компании по ИНН»

Активити принимает на вход:
- `Inn` — ИНН для поиска;
- `IblockElementId` — ID элемента инфоблока для обновления поля `Заказчик`.

Возвращает:
- `CompanyId` — ID компании в CRM;
- `CompanyName` — название компании.

## Инфоблок «Заказы клиентов»

| Свойство | Код | Тип | Обязательное |
|----------|-----|-----|--------------|
| Сумма | `SUM` | Число | Нет |
| Заказчик ИНН | `CLIENT_INN` | Строка | Да |
| Заказчик | `CLIENT` | Привязка к элементам CRM (Компании) | Нет |
| Вид работ | `WORK_TYPE` | Строка | Нет |
