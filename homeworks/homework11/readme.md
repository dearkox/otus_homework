
# Домашнее задание #11 Локальное REST приложение дата последней коммуникации

### Цель:
- создание REST приложений;
- обработка событий системы;
- отправка команд, для изменения данных в системе.

### Описание/Пошаговая инструкция выполнения домашнего задания:
Создайте автоматическое обновление даты последней коммуникации

### Пошаговая инструкция:
Добавить в карточку контакта пользовательское поле “Дата последней коммуникации”.
Создать приложение, обработчик которого будет отслеживать события создания дела, и записывать текущую дату и время в это поле, в карточке соответствующего клиента.

# Решение
Для реализации включил демо-доступ что бы заработала поддержка REST API приложений.
Создано локальное REST-приложение, которое подписывается на событие `onCrmActivityAdd` (создание дела в CRM). При создании дела, связанного с контактом, приложение получает ID дела из входящего POST-запроса от Битрикс24, запрашивает информацию о деле через `crm.activity.get`, определяет связанные контакты и обновляет поле `UF_CRM_LAST_COMM` через `crm.contact.update`.

Приложение имеет установщик (`install.php`), который при первоначальной установке:
- Проверяет, существует ли пользовательское поле `UF_CRM_LAST_COMM` в карточке контакта;
- Если поле отсутствует — создаёт его автоматически через `crm.contact.userfield.add`;
- Регистрирует обработчик события `onCrmActivityAdd` через `event.bind`.

Это позволяет полностью автоматизировать развертывание приложения без ручного создания полей и настройки событий.
