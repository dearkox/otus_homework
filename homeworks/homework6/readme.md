# Домашнее задание №6
Разработка модуля для расширения стандартного модуля CRM

### Цель:
создать собственный модуль;
научится работать с внешними таблицами;
сделать собственный компонент как элемент модуля;
работа со стандартными GRID компонентами.

### Описание/Пошаговая инструкция выполнения домашнего задания:
Написать модуль который добавить вкладку в CRM и выведет данные в грид из произвольной таблицы в БД.

### Пошаговая инструкция:

добавьте таблицу из дампа базы или создайте свою (аналогичную);
напишите компонент, который будет работать с этой таблицей;
сделайте модуль который будет принимать событие отрисовки табов (onEntityDetailsTabsInitialized) и возвращать наш компонент.

### Критерии оценки:
При открытии любой сущности CRM мы должны увидеть кастомный TAB;
При открытии TAB мы увидим список данных из внешней таблицы привязанных к ID сущности CRM;
При удалении модуля вкладка должна исчезать из карточки CRM.

### Уточнение от преподавателя:
Для выполнения задания можно создать любую кастомную таблицу с демонстрационными данными, отдельный дамп использовать не требуется.
При открытии карточки соответствующей сущности на кастомной вкладке должен отображаться грид, данные в котором берутся из вашей кастомной таблицы (2-3 записи) и привязаны к ID этой сущности

 # Реализация модуля
Установка модуля осуществляется через административную панель.
Модуль добавляет в карточки CRM (сделки, лиды, контакты, компании) новую вкладку «Свои заметки».
Таблица создаётся автоматически через ORM при установке модуля (использовал пример из другого урока курса `CrmNotesTable::getEntity()->createDbTable()`) 
Внутри вкладки — грид со списком заметок, привязанных к текущей сущности. Данные хранятся в таблице crm_notes.
Туда заливаются демо-записи. При удалении — таблица удаляется.
Вкладка подгружается лениво (по клику), внутри используется стандартный bitrix:main.ui.grid.
Модуль написан на `D7`, использует `ORM`, событие `onEntityDetailsTabsInitialized` и собственный компонент `crm.notes.grid`.
