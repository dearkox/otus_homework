# Домашнее задание №5

## Необходимо создать собственный компонент
Он будет иметь всего один параметр - выпадающий список, в котором можно будет выбрать валюту из списка,   
доступного по адресу /bitrix/admin/currencies.php.
Компонент будет выводить в шаблон текущий курс выбранной валюты,   
который можно узнать в том же справочнике по адресу /bitrix/admin/currencies.php.
Разместить компонент следует на странице /otus/currencies.php.

# Основная логика
Выбор валюты осуществляется через `режим правки` в настройках компонента в выпадающем списке.   
Или не посредственно в файле вызова компонента `otus/currencies.php`
 
# Файловая структура 
```
├── local/
│   └── components/
│       └── otus/
│           └── currencies.selector/
│               ├── .description.php        # Описание компонента 
│               ├── .parameters.php         # Параметры компонента (список валют)
│               ├── class.php               # Основной класс компонента (логика получения курса)
│               └── templates/
│                   └── .default/
│                       └── template.php    # Шаблон вывода курса валюты
├── otus/
│   └── currencies.php                      # Страница с подключением компонента
└── readme.md                               # Текущий файл
```
