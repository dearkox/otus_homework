## 0. Закрепление знаний по уроку и практическое их применение

Обновлён Composer, установлен `symfony/var-dumper`. Выведен список установленных пакетов.

## 1. Создать файлы для ДЗ согласно репозиторию https://github.com/OtusTeam/bitrix24.

Создана структура `/local/lib/` для хранения классов по PSR-4. Написан `autoload.php`. Класс `SergeyPr\Debugger\Debug` находится в `/local/lib/Debugger/Debug.php`. Продемонстрирован метод `Debug::dump()`.

## 2. В нем написать код, который при обращении по HTTP будет записывать в файл текущие дату и время.

Реализована проверка `isset($_SERVER['REQUEST_METHOD']) && php_sapi_name() !== 'cli'`. В `/local/logs/access.log` дописывается дата, время и метод запроса. Выведено содержимое лога.

## 3. Написать и подключить собственный класс системного логгера, который будет переопределять форматирование строк лога — добавлять слово OTUS в каждую строку.

Использован `/local/.settings_extra.php`. Подключён класс `\SergeyPr\Debugger\Debug` как обработчик исключений. Класс наследует `FileExceptionHandlerLog`, переопределяет `write()`, добавляя в лог `OTUS Logger`. Вызовом несуществующей функции `unExistFunction()` спровоцирована ошибка, обработанная новым логгером. Выведено содержимое `/local/logs/exceptions.log`.
