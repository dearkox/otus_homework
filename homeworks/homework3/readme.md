# Файловая структура домашнего задания №3

## Корень сайта

```
# файлы для этой дирректории лежат в корне
/doctors/
├── index.php # Главный файл-роутер (вся логика маршрутизации и вывода)  
└── style.css # Стили для страниц врачей
  
/local/  
├── php_interface/  
│   └── init.php                # Подключение автозагрузчика классов  
├── lib/  
│   ├── autoload.php            # PSR-4 автозагрузчик для пространства SergeyPr  
│   └── Medical/   
│       ├── DoctorManager.php   # Добавление/обновление врачей  
│       ├── DoctorView.php      # Вывод списка, детальной карточки, получение данных  
│       └── ProcedureManager.php # Добавление процедур, получение списка  
```  

Для поля `NAME` я использую формат ФИО, для удобства чтения и простоты вывода. Для домашней задачи этого хватит,
но я учитываю что для реальной рабочей версии сайта придётся добавлять обработчик события который при каждом изменении инициалов должен будет обновлять это поле.

## Ифоблоки

### Врачи (ID 16)

| Свойство | Код | Тип |
|----------|-----|-----|
| Фамилия | LAST_NAME | Строка |
| Имя | FIRST_NAME | Строка |
| Отчество | MIDDLE_NAME | Строка |
| Процедуры | PROCEDURES | Привязка к элементам (множественная) |

### Процедуры (ID 17)

| Свойство | Код | Тип |
|----------|-----|-----|
| Название процедуры | PROCEDURE | Строка |


## Маршруты (ЧПУ)

Все URL, начинающиеся с `/doctors/`, направляются в `/doctors/index.php` через правило в `/urlrewrite.php`:

```php
array(
    "CONDITION" => "#^/doctors/#",
    "RULE" => "",
    "ID" => "",
    "PATH" => "/doctors/index.php",
    "SORT" => 100,
)
```

## Доступные URL по разделу:
- `/doctors/` — список врачей
- `/doctors/new` — добавить врача
- `/doctors/newproc` — добавить процедуру
- `/doctors/{code}` — карточка врача
- `/doctors/edit/{code}` — редактирование врача
