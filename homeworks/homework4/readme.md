# Основная логика
Для выполнения домашнего задания (дабы не ломать структуру) использовал 2 уже существующих инфоблока  
Врачи(ID16 /bitrix/admin/iblock_list_admin.php?IBLOCK_ID=16&type=lists)  
Процедуры(ID 17 /bitrix/admin/iblock_list_admin.php?IBLOCK_ID=17&type=lists)
(полные ссылки будут в отчёте сдачи дз)
Где уже существует связь `Many to Many` (Врачи - Процедуры)
Соответственно данные для `INSERT` взяты с учётом реальных связей.  
В вашем примере вы создаёте связную таблицу с именем и фамилией и возрастом.  
Напоминает немного антипаттерн(так как при изменении фамилии или имени в контакте данные станут не актуальны).  
Для практики работы с ORM я решил подтянуть связь с таблицей `Контакты` через `Reference`
и добавлю виртуальные поля `FIRST_NAME` `LAST_NAME` `PHONE` через `ExpressionField`.
(Хотя эти данные и излишни для связной таблицы)

    PROCEDURE_ID INT NOT NULL,
    APPOINTMENT_DATE DATETIME NOT NULL,
    CREATED_AT TIMESTAMP DEFAULT CURRENT_TIMESTAMP
