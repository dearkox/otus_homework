# Домашнее задание №7
Создать свой тип поля для элементов инфоблока

### Цель:
- подключение кастомных скриптов к проекту;
- написание кастомного свойства;
- работа с Bitrix.UI библиотекой.

### Пошаговая инструкция:

- создать список Бронирование с полями ФИО пациента, Время записи, Процедура;
- добавить кастомное свойство, в выводе кастомного свойства показать все процедуры которые связаны с врачом; 
- подключить BX.PopupWindowManager по клике на процедуру;
- при заполнении всех полей, создавать бронирование;

# Описание реализации 

## Основная логика
Для выполнения задания использовал уже существующие инфоблоки:
- Врачи (ID 16)
- Процедуры (ID 17)   
Связь `«Врачи — Процедуры»` — `Many to Many` через множественное свойство `PROCEDURES` у врачей.   
Кастомное свойство Запись на процедуры `PROCEDURES_RECORDS` выводит в публичном списке врачей список процедур, привязанных к конкретному врачу.   
Каждая процедура — это ссылка, которая открывает модальное окно для записи.
В модальном окне — ФИО пациента и дата/время (календарь Битрикс).   
После отправки данные уходят в обработчик `/local/ajax/booking.php`, который создаёт элемент в инфоблоке `«Бронирование»` с привязкой к процедуре и врачу.   
Для документации js скрипта использован формат `JSDoc`.
